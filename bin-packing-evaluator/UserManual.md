# User Manual: Bin Packing Evaluator

## Requirements

- **Compiler:** g++ with C++17 support. Just like in project 3, the Makefile forces -O3 optimization to avoid artificially hitting the runtime wall prematurely. This is necessary for the computationally complex brute-force optimal solution included in the program.
- **Operating System:** Linux
- **Input File:** _items.txt_ must be present in the project root directory. Bins are of unit size, so valid items must strictly be greater than 0 and less than or equal to 1. Invalid items will not be processed by the program.
