# COP 4534 — Algorithm Techniques

Course projects for COP 4534, written in C++.

| Project | Folder |
| --- | --- |
| Traveling Salesman Problem (brute force and genetic algorithm) | `traveling-salesman-problem/` |
| Longest Common Subsequence | `longest-common-subsequence/` |
| Bin Packing Evaluator | `bin-packing-evaluator/` |

Each project has its own `Makefile`, UML diagram, and user manual. Build with `make` inside the project folder.
